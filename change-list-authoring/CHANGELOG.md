# change-list-authoring 技能升级记录

## v1.1（2026-11-02）

### 背景

原技能覆盖页面/字段矩阵、字典同步和跨仓核对，但当一次变更改变的是被多页面/多端消费的横向规则或文档权威结构时，CR 容易只列代码/页面任务，把规则散落、下游摘要、双端差异和同类文档排查留给执行者临场发挥。该问题与具体业务领域无关。

### 变更

- 新增 `references/rule-and-doc-impact.md`：横向规则/共享字段/文档结构变更的影响矩阵、任务类型、双端同步、全量排查、文档质量验收与反模式。
- `SKILL.md`：阅读顺序增加该参考；工作流程第 3 步要求判断横向规则并建影响矩阵；质量门槛增加“横向规则有传播”“文档质量可验收”。
- `change-list-template.md`：§8.3 新增横向规则与文档结构变更矩阵；§7.4 文档验收补权威唯一、摘要/回链、可读性、双端边界、链接/结构检查。
- `review-method.md`：增加横向规则/多消费方核对；`dual-repo-and-review.md`：增加消费方矩阵与单权威要求。
- 保持比例：普通单页小改不强制全量排查；横向规则、同类反馈或明确要求时启用。
- **验收修订（2026-11-02）**：`project-patterns.md` 移除具体项目名与本机绝对路径，只保留结构借鉴与通用要求；`rule-and-doc-impact.md` 明确写作细则引用 `prd-rule-authoring` 横向规则规格，避免重复维护。

### 验证

- 以“配置页 + 交易页 + 详情页 + 另一端”的规则标识类变更为回归样例，检查 CR 是否能生成影响矩阵、下游摘要/回链、双端差异/待承接与全量排查任务；
- 由独立模型验收，不以示例项目名称写入技能。
