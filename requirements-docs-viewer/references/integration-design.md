# 入口、构建与映射设计

## 1. 入口位置

- 常见位置：页面头部（面包屑旁）、页面工具条、侧边栏底部；选择不遮挡主操作、不改变布局语义。
- 可见条件：**有文档映射 + 总开关开启**；无映射页面不渲染，避免死按钮。
- 入口文案用业务语言（如「需求说明」），不用「文档」「MD」等实现词。
- 入口零数据加载：按钮渲染不得触发文档请求或索引构建。

## 2. 文档来源与构建复制

- 文档源：仓库内 Markdown 目录（单一来源），或文档系统导出的静态文件。
- 构建期复制到产物目录（如 `dist/rule-docs/`），运行时只读产物，不在运行时访问仓库。
- **双向校验**：构建结束对比「映射清单」与「产物目录」：
  - 映射有、产物无 → 构建失败（缺文件）；
  - 产物有、映射无 → 构建失败（孤儿文件）。
- 清理旧产物：构建前清空目标目录，避免历史文件残留。
- 子路径部署：所有 URL 基于部署 base 拼接，不对根路径硬编码。

## 3. 映射注册表

- 唯一映射源：路由/页面 → 文档（id、标题、模块、路径、类型 page/global）。
- 菜单叶子、动作页、提示页分别登记；动作页可带「章节提示」（按标题文本定位）。
- 映射完整性测试：叶子/动作页全覆盖、路径存在、标题唯一、模块分组正确。
- 文档树展示：模块分组 + 模块级文档标识（如「全局」徽标）；当前文档高亮。

## 4. 开发与生产差异

| 环境 | 读取方式 | 目的 |
|---|---|---|
| 开发（dev） | 中间件按请求实时读仓库文档 | MD 改动刷新即生效，不需要重建 |
| 构建/预览/生产 | 构建期复制产物 | 静态、可缓存、可审计 |

- 两者路径规则一致，避免 dev 与产物行为分叉。
- 开发中间件仅 dev 启用；需防目录穿越（规范化路径 + 前缀边界检查）与不存在文件 404。

## 5. 懒加载红线

- 应用启动零文档请求；
- 入口组件本身不预载文档/渲染器 chunk；
- 首次打开才加载当前文档与渲染逻辑；搜索索引在打开后空闲建立（失败可重试）；
- 已加载文档进缓存（按映射 id），关闭重开/目录来回切换不重复请求；并发切换的竞态守卫见 rendering-and-search §3；
- 用请求计数测试锁定红线（打开前 0，打开后 >0）。

## 6. 生产暴露面

- 入口开关（如 `RULE_DOCS_ENTRY_ENABLED`）只控制按钮可见性，**不保护静态文档**；
- 生产二选一：构建排除文档目录，或对文档路径加服务端鉴权；
- 在《生产接入门禁清单》登记，未处置前不得宣称可对外交付。

## 7. 阅读器窗口与目录交互（2026-10 升级经验）

来自一次真实验收两轮反馈的通用教训，适用于抽屉/面板式阅读器：

**窗口与版式**

- 阅读区宽度是首要体验项：抽屉 ≥75% 视宽，并提供最大化/还原（100% ↔ 原宽）；左文档树降宽（如 300→240px）让给正文。
- 左树模块分组标题做层级视觉（加粗提对比、组间分隔、层级字号递减）；文档头附注/备注类引用块降为次要字号（如 12px）；段落/列表/标题间距与行距（如 1.75）统一润色。

**目录：默认折叠 + 吸顶一行头部**

- 目录**默认折叠为一行吸顶头部**（sticky top:0），深滚常驻；折叠态头部显示「当前：章节名」，展开态当前条目高亮。
- **展开列表必须限高内滚**（如 `max-height: 45vh; overflow-y: auto`）：整块 sticky 的目录若无限高，高度超过正文容器时深滚会完全遮挡正文（实测 832px > 666px）。限高后整块 sticky 可保留。
- 展开/收起改变正文上方内容高度，**按列表高度补偿 scrollTop**（收起 −listHeight / 展开 +listHeight，钳制合法区间）保持视口内容不动；toggle 用 `@mousedown.prevent` 阻断点击聚焦引发的原生滚动，收起前摘除目录列表内焦点（焦点元素隐藏会触发浏览器原生滚动归零，不经过 JS 可见 setter）。

**点击定位防吸顶遮挡（易漏）**

- `scrollIntoView({block:'start'})` 会把目标标题滚到容器顶部——若目录吸顶，标题正好落在目录正下方被完全遮挡。改为手动定位：`scrollTop = 标题文档位 − 吸顶目录覆盖高度 − 8px`。
- **覆盖高度 = 吸顶目录底边 − 正文容器顶**（getBoundingClientRect 实测，含容器 padding；折叠/展开分别计算，不用 offsetHeight 近似——容器 padding 会造成十余像素偏差）。
- 正文滚动跟随的「当前章节」阈值同样按覆盖高度计算（覆盖高度 + 余量），不用固定 px；点击跳转的锚点在视口可见期间**优先计为当前章节**（跳转锚点模式），否则折叠补偿保持视口不动后，纯阈值计算会把当前章节回退到前一节。

**自动化补盲**

- `toBeVisible()` 不判遮挡：深滚遮挡与点击定位遮挡都需**遮挡级断言**（如目标标题 `boundingBox().y ≥ 吸顶目录底边`）才能锁定，否则全量自动化全绿仍可能漏检（真实项目中出现过全绿仍漏遮挡的案例，具体计数不写入通用技能）。
