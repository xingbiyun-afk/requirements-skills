# 渲染、历史过滤与搜索

## 1. 受限 Markdown 渲染

支持语法（按项目文档实际使用取交集）：标题 h1~h6（目录只收 level≤3）、段落、有序/无序列表（含嵌套）、表格（转义 `\|`）、行内代码、围栏代码、引用、分隔线、粗体、链接（http/https）。

实现要求：

- **先整体转义**再拼接受限标签；只输出白名单标签，禁止内联 HTML/事件属性/`javascript:` 协议；
- 相对路径链接（如 `./xxx.md`、`docs/…`）**降级为纯文本**，不在产物内产生死链；
- 图片语法不渲染：按纯文本降级（或显式取 alt 文本），不请求外部图片资源；
- 表格按转义后的 `|` 切列；嵌套列表保留层级；
- 标题生成唯一锚点（重名标题加序号），供目录与搜索跳转；锚点 slug 在去行内标记后**把 HTML/URL 危险字符 `<>&"'` 替换为 `-`**——纯预防加固：getElementById 链路下实体转义本可达，但危险字符锚点对 CSS 选择器/URL hash 上下文不安全。**变更 slug 规则前必须校验存量文档标题无该类字符、保持既有锚点稳定**，再全量回归目录/搜索/定位；
- 不支持的语法降级为转义文本，不破版、不执行；
- 渲染器纯函数化，便于单元测试（正例 + 注入用例 + 边界）。

## 2. 历史章节过滤（阅读器规则）

- **不渲染 level-2 标题为「更新记录」「更新日志」的章节**（标题到下一个同级/更高级标题前的内容），不在目录出现、不被搜索索引；
- 过滤在解析层统一完成，目录/正文/搜索共用同一份结果；
- 过滤词表是项目约定（当前两个词头），扩展新词头时同步补样本测试，防止误杀正文同名章节；
- **边界形态处置矩阵**（超出 level-2 标题形态的部分）：
  | 形态 | 处置 |
  |---|---|
  | level-2「更新记录/更新日志」章节 | 解析层过滤（本规则） |
  | level-3 及以下历史子章节 | 随父章节一并剔除；若无父章节，靠写作侧约定不在阅读层写 |
  | 引用块/代码块内的历史快照 | 不过滤（无法与安全区分），由写作侧约定不在阅读层写 |
  | 正文内联「历史注记」（如「旧版曾…」） | 不过滤，由写作侧约定与评审兜底 |
- 过滤是防御，不替代写作规范；历史可追溯性由源文档/变更记录/git 承担，不在阅读器呈现。

## 3. 目录与定位

- 目录按 level≤3 收录，当前滚动位置高亮可选；
- 点击目录滚动到锚点；
- 动作页支持「章节提示」：按标题文本包含匹配首个命中，找不到退回文档顶部；
- 锚点定位容器要正确（滚动发生在正文容器，不是外层 section）；
- **加载竞态**：快速连续切换文档时用单调序号守卫（后发起者覆盖前者，过期响应直接丢弃），错误态与加载态按最后一次请求落定；已加载文档按 id 缓存，关闭重开不重复请求。

## 4. 全局搜索

- 索引内容 = 渲染后的正文（剔除历史章节后），按文档/章节归属；
- 建立时机：首次打开后空闲建立；失败进错误态可重试；构建中重复触发要合并；
- 结果含：模块、文档标题、章节、命中片段（关键词高亮，先转义再包 mark）；每文档限条数防刷屏，排序规则稳定（如模块→文档→章节顺序）；
- 点击结果跳转目标文档对应章节（跨文档）；
- 索引规模较大时分批/受限并发，避免阻塞 UI；索引常驻内存时设上限（条数/文档数），超限时降级为「仅当前文档内搜索」并明示。
- **结果按文档分组展示**（组头 = 模块 / 文档标题 / 条数），并支持**当前所在页文档命中置顶**；分组与置顶下沉为纯函数（组序 = 文档树顺序、组内保序、不改变条目原顺序），便于单测。
- **命中片段降噪**：片段（及匹配文本）去除行首列表标记、标题 `##` 标记、表格 `|`、行内强调与行内码——匹配与片段同源处理，展示不出现 Markdown 噪音（分组解决「杂乱」后，片段里的 `**`/`-` 仍是噪音）。

### 4.1 搜索结果导航上下文

点击搜索结果只切换正文文档，不结束搜索：

- **不清空**搜索词、结果列表和结果区滚动位置；返回/清空必须是显式动作。
- **当前命中高亮**：用稳定 key（至少文档 + 锚点 + 标题；同章节多条命中再加片段）标识刚点击项；正文滚动离开该锚点后清除高亮。
- **清空搜索**：搜索框内清空或显式「清空搜索」按钮恢复文档树；清空时同步清除高亮、结果区滚动记录。
- **文档树打开**：从树点击文档时清空搜索，避免旧命中上下文带到新浏览路径。
- **不重建索引**：跳转只换文档，索引已就绪时不重新建立。
- **滚动恢复**：切文档后结果区可能因当前页分组置顶改变高度；恢复值按新的最大可滚动范围做 clamp，测试不要断言绝对值等于旧值。
- **关键词变化**：查询词改变时清除旧命中高亮；避免同一章节多条命中被误认为同一条。
- **可访问性**：高亮项提供 `aria-current` 等状态；清空按钮可键盘操作；不要依赖颜色作为唯一提示。

验收至少覆盖：搜索 → 点第 1 条 → 关键词/结果/滚动位置仍在 → 点第 2 条成功；清空搜索恢复树；高亮唯一且随滚离清除；树点击后搜索清空；索引未重建。

## 5. 错误态与空态

- 文档加载失败：显示可读错误 + 重试，不白屏；
- 文档不存在/无权限：提示并保留返回；
- 空文档：显示「暂无内容」；
- 搜索建立失败：错误提示 + 重试，不永久「建立中」；
- 网络挂起（无响应超时时）：fetch 设超时或 AbortController，超时按加载失败进错误态，不无限转圈。
