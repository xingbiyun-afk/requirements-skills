# 验收清单（阅读入口）

## 1. 逻辑/组件测试

- [ ] 映射：叶子/动作页/提示页全覆盖；路径存在；标题唯一；模块分组正确
- [ ] 渲染：标题/列表/表格/代码/引用/链接正例；HTML 注入全部转义；重复标题锚点唯一；表格转义管道不切列
- [ ] 历史过滤：含「更新记录/更新日志」样本被剔除（目录/正文/搜索）；映射文档零历史章节守卫
- [ ] URL 构造：子路径 + 中文/括号文件名分段编码
- [ ] 搜索：跨文档命中、归属正确、跳转锚点存在、高亮转义
- [ ] 入口可见性：开关关闭不渲染、无映射不渲染（行为断言，不只断言常量/源码字符串）
- [ ] 错误态：fetch 失败/重试路径

## 2. 构建与产物

- [ ] `build:all` 通过；产物文档数与映射一致；双向校验（缺失/孤儿即失败）
- [ ] lint 0；`git diff --check` 干净
- [ ] 产物内无归档/讨论稿/未映射文件

## 3. 浏览器自动化（预览构建）

- [ ] 入口可见并打开；默认定位当前页文档
- [ ] 目录切换文档、点击定位章节
- [ ] 目录默认折叠一行吸顶；展开限高内滚；深滚后正文不被目录遮挡（断言目录高/正文容器比例或正文可见高度 >0）
- [ ] **点击定位防遮挡**：点击目录条目后目标标题 `boundingBox().y ≥ 吸顶目录底边`（遮挡级断言——`toBeVisible()` 不判遮挡，此条缺检会漏掉定位被盖缺陷）
- [ ] 目录折叠/展开滚动补偿：视口内容基本不动（误差 ≤ 数 px）；折叠态「当前：章节名」正确
- [ ] 正文滚动跟随：当前章节随滚动更新；点击跳转后该章节在视口可见期间保持为当前
- [ ] 全局搜索命中、跳转
- [ ] **搜索结果上下文保持**：点击命中后关键词/结果列表/结果区滚动位置保留；可直接点击下一条命中并切换高亮；不重建索引
- [ ] **清空搜索**：显式清空恢复文档树、清除高亮；从文档树打开文档时搜索清空
- [ ] **命中高亮**：仅当前命中项高亮；正文滚离锚点后清除；同章节多条命中可区分
- [ ] 滚动位置恢复对「当前页」组置顶导致的 clamp 容忍，不断言像素级绝对相等
- [ ] 搜索结果按文档分组；当前页文档置顶且带「当前页」标；片段无 Markdown 噪音（无 `- `/`**`/`##`/`|` 残留）
- [ ] 动作页默认定位章节
- [ ] 非 MVP/提示页映射正确
- [ ] 错误态（请求拦截或临时缺文件）可读
- [ ] 懒加载：打开前文档请求 0、渲染器 chunk 0；打开后 >0
- [ ] 历史章节不出现（正文/目录/搜索）
- [ ] 关闭重开：状态复位正确、已读文档不重复请求
- [ ] 快速连续切换文档：无竞态错文（序号守卫生效，最终显示最后一次选择）
- [ ] 超大文档：打开与目录渲染可接受（不卡死、内存不暴涨）
- [ ] 键盘可访问性：Esc 关闭、打开后焦点进入抽屉（按项目 a11y 基线取舍）
- [ ] 窄屏/移动端宽度：不破版或按项目决策登记「桌面端 only」

## 4. 可见浏览器走查

逐条：入口 → 操作 → 预期 → 截图/请求计数，归档到项目证据目录并登记台账。至少覆盖：入口默认定位、文档树切换、搜索跳转、动作页定位、提示页、错误态、懒加载、无历史内容。**截图必须与最终行为一致**：验收修补后重拍替换旧行为图（如目录限高前后、片段降噪前后的截图），不留「修补前旧图」充当现行证据。

## 5. 安全与生产

- [ ] 渲染无 XSS（转义/白名单/协议限制）
- [ ] 开发中间件防目录穿越
- [ ] 生产暴露面已处置（排除目录或鉴权）并登记门禁
- [ ] 不把「开关关闭」当作防护充分

## 6. 证据分层

文档检查、逻辑测试、构建、自动化、可见浏览器、CI 分别记录；跳过或未执行明确标注，不以一端证据代替全部。状态与证据纪律（PR 未合并不写关闭、main run 证据不错挂、计数用实数、超范围改动补登记）见 `ops-and-governance.md` §7。
