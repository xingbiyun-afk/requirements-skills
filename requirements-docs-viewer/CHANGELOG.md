# requirements-docs-viewer 技能创建记录

## v1.3（2026-11-02）

### 背景

阅读器已有搜索分组、当前页置顶和片段降噪，但实际使用中，点击搜索结果后会清空关键词和结果列表；读者定位到错误位置时必须重新输入关键词，无法连续查看多个候选命中。该问题属于阅读器的通用搜索导航体验，不是某个项目的特殊需求。

### 变更

- `SKILL.md` 最小实现第 7 条补“搜索结果导航上下文”：点击命中保留搜索词/结果/滚动位置；命中高亮；显式「清空搜索」恢复文档树；树打开时清空；不重建索引。第 9 条补对应测试与 clamp 容忍。
- `references/rendering-and-search.md` 新增 §4.1：稳定命中 key、结果区滚动恢复、关键词变化清高亮、可访问性、验收场景。
- `references/acceptance-checklist.md` 浏览器自动化补搜索上下文、连续命中、清空恢复树、高亮唯一、滚动 clamp 容忍断言。
- 全文不涉及文档写作规范；与 `prd-rule-authoring` 的边界不变。
- **验收修订（2026-11-02）**：`integration-design.md` 去掉具体项目计数，改为通用的“全绿仍可能漏遮挡”教训；避免项目事实写进通用技能。

### 来源与验证

- 实践来源：某阅读器搜索结果定位后清空、无法连续查看候选的体验问题（不绑定具体项目/业务名称）；
- 验证：搜索→命中→结果/关键词/滚动保持→连续命中→清空恢复树；由独立模型验收。


## v1（2026-10-23）

### 背景

某交付项目已在应用内实现页面需求说明阅读入口（抽屉、目录、全局搜索、懒加载、生产暴露面门禁）。该能力与文档写作技能混在同一技能中会导致两者互相绑定；本技能独立承载入口实现。

### 范围

- 入口位置与可见条件；
- 文档来源、构建复制、双向校验；
- 映射注册表与文档树；
- 受限 Markdown 渲染、历史章节过滤、搜索；
- 懒加载、错误态；
- 生产暴露面与门禁登记；
- 测试与可见浏览器走查。

### 不包含

- 文档写作规范（见 `prd-rule-authoring`）；
- 文档内容质量验收；
- 在线编辑/评论/审批流。

### 与 prd-rule-authoring 的关系

仅共享「文档目录 + Markdown 约定」，互不依赖；没有阅读入口的项目仍应产出需求文档。
