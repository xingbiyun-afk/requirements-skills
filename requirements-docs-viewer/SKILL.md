# 页面内需求文档阅读入口

## 目标

把项目里**已经写好的需求文档**接到产品界面上，让人在当前页面直接查对应的说明。同时保证：不拖慢首屏、不显示历史内容、不在生产环境意外暴露内部文档。

## 和文档写作的边界

- 本技能只负责阅读入口的实现：入口位置、文档映射、构建复制、渲染、搜索、懒加载、错误态、生产暴露、测试与走查。
- 文档内容谁写都行，本技能**不规定**怎么写，也不要求项目用 `prd-rule-authoring`。
- 两者互不依赖：没有阅读入口的项目也要写需求文档；有入口也不改变写作规则。
- 唯一的接口是「文档目录 + Markdown 约定」：路径、标题、能渲染的语法。约定写在项目配置里，不写死在技能里。

## 什么时候用

- 产品/开发/测试希望在当前页面直接看规则，不用分屏查 MD；
- 已经有成体系的 Markdown 需求文档，需要只读展示；
- 要把内部文档接进交付演示，但必须控制生产可见性。

不适用：在线编辑、评论协作、文档审批、做成全文检索服务、按权限分级阅读。

## 最小实现清单

1. **入口**：只在有文档映射的页面显示；没映射不渲染，不留死按钮；入口本身不加载文档。
2. **来源**：文档源是仓库里的 Markdown（或等价静态文件），构建时复制到产物目录，并校验构建产物和映射表对得上——缺文档或多出文档都算构建失败。
3. **映射**：路由/页面 → 文档路径的注册表是唯一映射源；文档树按模块分组；模块级文档单独标出。
4. **加载**：抽屉/面板打开后才请求文档；首次打开加载当前文档；搜索索引打开后再空闲建；启动时不预载。
5. **渲染**：只渲染受限 Markdown（标题、段落、列表、表格、代码、引用、分隔线、链接）；全部 HTML 转义，只输出白名单标签；中文和带括号的文件名做 URL 编码；适配部署在子路径；标题锚点过滤 `<>&"'` 等危险字符，锚点生成只留一个出口（目录、正文、搜索、定位共用）。
6. **只显示最新说明**：不渲染「更新记录/更新日志」章节及其内容，目录和搜索也排除；来源文档里如果有历史注记，按项目约定过滤，或让作者不写。
7. **交互**：目录点击定位；动作页可按章节默认定位；全局关键词搜索（按文档分组、当前页命中置顶、片段去掉 Markdown 噪音）并可跳转；有错误态和重试；能关闭。搜索结果要保住上下文：点命中只换正文，不清空搜索词和结果列表，保留结果区滚动位置，命中项高亮（key 稳定，至少含文档+锚点+标题），提供「清空搜索」恢复文档树，从文档树打开文档时清空搜索，不重建索引。
   **红线**：目录如果吸顶或常驻正文上方，点击定位必须按被盖住的高度偏移，否则目标被挡住；自动化要用「遮挡」级别的断言，`toBeVisible` 判不出遮挡。吸顶折叠、滚动补偿等进阶形态见 `integration-design.md` §7。
8. **生产暴露**：入口开关只管按钮，不保护静态文档。生产必须二选一：构建时排除文档目录，或给文档路径加鉴权，并写进生产接入门禁。
9. **测试**：映射完整性、构建产物一致、历史章节不显示、懒加载零预载、搜索与跳转、搜索结果上下文保持（词/结果/滚动位置保留，连续命中，清空恢复树，高亮唯一，不重建索引）、错误态；目录和定位补遮挡级断言；滚动恢复断言允许 clamp 误差，不要求像素级相等；可见浏览器走查并归档证据，截图要和最终行为一致。

## 边界

- 不改业务页面行为、菜单/路由业务值、Mock 数据；只加阅读入口和文档资产链路。
- 不引入重型第三方 MD 渲染依赖；渲染器受限、可测、可转义。
- 不把文档写作规范写进本技能，也不把入口实现细节写进写作技能。
- 查看器通过只证明入口、映射、渲染、搜索、错误态可用，不证明文档内容完整；后者由写作和 CR 验收负责。
- 真实权限、生产部署和鉴权方式以项目门禁为准；Mock/演示跑通不等于生产已防护。

## 交付时说明

入口位置和显示条件、文档来源与映射、构建复制与校验、渲染与历史过滤、懒加载与搜索、错误态、生产暴露处理、测试与走查证据、没覆盖的部分。
